# アルティメット割り箸

ブラウザだけで遊べる「アルティメット割り箸」です。

## 構成
- React 18
- Tailwind CSS CDN
- PeerJSによるブラウザ間オンライン対戦
- CPU戦は元のゲームロジックを使用

## ローカル確認
HTTPサーバーでフォルダを配信してください。`file://` で直接開くのではなく、VS CodeのLive Serverなどを使います。

## 公開
このフォルダをGitHubへアップロードし、Vercelなどの静的ホスティングに接続すると公開できます。

## 注意
オンライン対戦の接続確立にはPeerJSの公開シグナリングサーバーを利用しています。ゲーム状態そのものはホストとゲストのブラウザ間で送受信します。
